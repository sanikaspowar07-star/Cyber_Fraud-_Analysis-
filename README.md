🔐 Cyber Fraud Analysis

📌 Project Overview

Cyber Fraud Analysis is a Data Analytics project focused on analyzing cyber fraud complaints, identifying fraud patterns, and understanding financial losses.

This project uses Python, SQL, and Power BI to clean, analyze, and visualize cyber fraud data.

🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Jupyter Notebook

📊 Project Workflow

1. Data Cleaning & Analysis (Python)

- Checked missing values and duplicate records.
- Cleaned and processed the dataset.
- Performed Exploratory Data Analysis (EDA).
- Analyzed financial loss and victim age.

2. SQL Analysis (MySQL)

- Created and analyzed the cyber fraud database.
- Used SQL queries for data analysis.
- Analyzed fraud types, states, and complaint status.

3. Dashboard (Power BI)

Created an interactive dashboard to visualize:

- Total Complaints
- Total Financial Loss
- Complaints by Crime Type
- Complaints by Status
- Financial Loss by Crime Type
- State and Crime Type filters

📈 Key Project Highlights

- Analyzed 10,000 cyber fraud records.
- Total financial loss displayed: 277.71M.
- Identified different cyber fraud categories.
- Created an interactive Power BI dashboard.
